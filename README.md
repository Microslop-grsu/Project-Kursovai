## 📋 Описание проекта

**ShelterCore: Happy Tails** — это комплексная система управления приютом для животных, разработанная на C++20. Проект предоставляет функциональность для:

- 🐕 **Управления животными** - каталогизация и отслеживание собак, кошек, птиц и экзотических животных
- 🍖 **Мониторинга питания** - автоматический расчёт рационов, учёт потребления пищи через "умные" кормушки
- 💊 **Ведения медицинских карт** - регистрация и отслеживание здоровья каждого животного
- 📊 **Обработки событий** - система логирования и анализа событий в приюте
- 💾 **Управления данными** - загрузка и сохранение информации о животных в JSON формате

## 🚀 Начало работы

### Требования

Для сборки и запуска проекта необходимо установить:

- **CMake** ≥ 3.8
- **C++20 компилятор** (GCC ≥ 10, Clang ≥ 11 или MSVC 2019+)
- **Git**

#### На Linux (Ubuntu/Debian)

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake git
```

#### На macOS

```bash
brew install cmake git
```

#### На Windows

Установите:
- [CMake](https://cmake.org/download/)
- [Visual Studio 2019+](https://visualstudio.microsoft.com/) или другой C++20 компилятор
- [Git](https://git-scm.com/download/win)

### 📦 Сборка проекта

```bash
# Клонируем репозиторий
git clone https://github.com/yourusername/ShelterCore.git
cd ShelterCore

# Создаём директорию сборки
mkdir build
cd build

# Конфигурируем проект с помощью CMake
cmake ..

# Собираем проект
cmake --build .
```

### ▶️ Запуск программы

После успешной сборки:

```bash
# На Linux/macOS
./Shelter

# На Windows
.\Shelter.exe
```

Программа автоматически загрузит данные о животных из `data/pets.json` и запустит интерактивное консольное приложение.

## 📁 Структура проекта

```
ShelterCore/
├── include/shelter/          # Заголовочные файлы
│   ├── core/                 # Классы животных и медицинских записей
│   ├── services/             # Бизнес-логика (управление приютом, питание, события)
```

| **ConsoleView** | Интерактивный консольный интерфейс |

## 🛠️ Разработка

### Добавление нового типа животного

Для добавления нового типа животного:

1. Создайте класс в `include/shelter/core/`, наследующий `Pet`
2. Реализуйте в соответствующем `*.cpp` файле
3. Зарегистрируйте в `PetFactory.cpp`
4. Добавьте в `CMakeLists.txt`

### Логирование

Используйте `Logger` для логирования событий:

```cpp
#include "shelter/utils/Logger.h"

Logger::info("Animal registered: " + petName);
Logger::error("Failed to load pet data");
```
